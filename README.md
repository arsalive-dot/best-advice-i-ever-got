# The Best Advice I Ever Got

One sentence on the best advice ever received: a grandmother's test for
a partner — soup when you're sick, not flowers when you're well.

## How it works

`main.py` (Python 3, standard library only) writes the sentence to
`/output/entry.txt` deterministically: it writes a temporary file, then
atomically replaces the final file and sets mode 644.
